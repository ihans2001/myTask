Flattened SW FMEA — 한 줄로 읽는 고장모드분석

SW 아키텍처링 테이블(함수 SSoT)로부터 차상위-초점-차하위 관계를 자동으로 펼쳐, 원인-현상-대책을 좌에서 우로 한 줄만 읽으면 파악되는 FMEA 템플릿을 만든다.
SW 아키텍처링 연계 AIAG-VDA 기반 상용 전용기능 자체 구현
01왜 필요한가
상용 툴 결과는 읽기 어려움
복잡한 계층 구조를 셀 병합으로 표현해, 원인-결과 관계를 보려면 시선을 계속 오르내려야 한다
계층마다 담당자가 불명확
누가 어느 계층을 작성할지 사람마다 다르게 해석되기 쉽다
아키텍처가 바뀌면 따로 놈
SW 구조가 바뀌어도 FMEA 표는 자동으로 갱신되지 않는다
제외 이유가 기록에 안 남음
특정 계층을 FMEA 대상에서 뺀 이유를 나중에 설명하기 어렵다
02무엇을 만드는가
①
Flattened SW FMEA 템플릿
차상위-초점-차하위 관계를 한 행에 평탄화해 좌→우로 읽는 표
②
자동 담당자 배정
계층 깊이에 따라 시스템엔지니어·리딩엔지니어·연구개발담당자를 자동 배정
③
FMEA 대상 여부 자동 기록
계층별 적용/제외 판단을 감사 가능한 형태로 남김
④
Excel Outline 계층 전개
접기·펼치기로 담당 구간만 골라 작업
핵심 원리
Next higher(차상위)-Focus(초점)-Next lower(차하위) 재귀 구조 SSoT 함수 트리를 슬라이딩 윈도우로 순회 AIAG-VDA 최신 AP 기준 적용
상용 전용 기능을 직접 구현
IQ-FMEA 등 상용 전용 툴에서만 가능했던 기능을 전용 함수로 재구현
03어떻게 동작하는가
1
함수 SSoT 순회
임의 노드를 초점요소로 고정하고 차상위·차하위 후보를 모두 찾는다
2
세트 자동 생성
초점요소가 N개의 차상위·M개의 차하위를 가지면 N×M개의 조합을 만든다
3
담당자·적용여부 부여
참조표(RoleMap) 기준으로 각 행에 담당자와 FMEA 대상 여부를 자동 기록한다
4
템플릿 배포
완성된 하나의 템플릿을 역할별 담당자에게 공유한다
5
계층별 작성
각 담당자가 Excel Outline으로 자기 구간만 펼쳐 고장모드와 조치를 채운다
04계층별 담당자 배정
계층
담당자
책임 범위
Firmware / ASW / BSW (상위)
시스템 엔지니어
아키텍처 수준 공통서비스 리스크 식별(선택적 적용)
Module (서브시스템)
리딩 엔지니어
모듈 단위 기능 안전/품질 리스크 총괄
Component / UnitFunction (말단)
연구개발 담당자
구현 최말단의 고장모드·개선조치 작성
담당자 매핑은 별도 참조표(RoleMap)로 관리한다 — 조직 기준이 바뀌어도 참조표만 수정하면 전체 보고서에 자동 반영된다.
05한 줄로 읽는 표기 규칙
기존 — 상용 툴 출력
셀 병합으로 표현된 복잡한 계층
N:(초점요소):M 구조를 셀 병합으로 표현해, 원인-현상-대책 관계를 파악하려면 상하좌우로 시선을 계속 옮겨야 한다.
신규 — Flattened 표기
차상위+초점+차하위를 한 행에
고장모드는 <NE>/<WV>/<UT> 3줄 고정 포맷으로 압축 표기한다. 좌에서 우로 한 줄만 읽으면 인과관계가 파악된다.
06기대 효과
리뷰 리드타임 단축
한 줄만 읽으면 원인-현상-대책이 파악된다
감사 대응력 강화
검토·제외 판단이 감사 가능한 형태로 남는다
담당자 배정의 일관성
참조표 기준 자동 배정으로 해석 차이가 사라진다
아키텍처 변경에 자동 대응
SSoT가 바뀌면 템플릿도 최신 구조로 다시 생성된다
07유의할 점
  • AP(Action Priority)는 RPN에서 역산되지 않는다 — AIAG-VDA 최신 기준의 별도 룩업표를 사용한다
  • 화면 표시는 압축하되 계산은 숨김 열에서 — 필터·정렬이 압축 셀에는 적용되지 않아 별도 계산열을 둔다
  • Excel Outline은 최대 8단계까지 지원해, 더 깊은 계층에도 동일한 원리가 적용된다
