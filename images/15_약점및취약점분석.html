IHANS-PRO-2026-015 2026-09-09 제안서

약점·취약점 분석 자동화

취약점 모니터링에서 넘어온 정보를 자산(Config/SBOM)과 자동으로 매칭하고, CVSS·EPSS·KEV 조회부터 TARA 연계 위험판정까지 하나의 흐름으로 이어간다.
VBA-Python 브릿지 로컬 임베딩 기본(보안) 전체 SBOM + Tier TARA 연계
01왜 필요한가
모니터링 이후가 더 큰일
신규 취약점을 찾은 다음, 우리 자산에 실제로 해당되는지 판단하는 작업이 더 오래 걸린다
벤더/제품명이 자산명과 다름
공개된 벤더/제품 표기와 사내 자산명이 정확히 일치하지 않아 매칭이 쉽지 않다
위험도 판단 기준이 제각각
CVSS만으로는 실제 악용 가능성과 우리 제품에 대한 영향을 알 수 없다
외주·오픈소스까지 다 봐야 함
자체개발뿐 아니라 외주·구매·오픈소스 구성요소까지 전부 살펴야 한다
02무엇을 만드는가
①
자산 자동 매칭
Vendor/Product/Version을 Config(SBOM)와 대조해 해당 자산을 자동으로 찾음
②
CVSS 자동 계산
v3.1/v4.0 벡터를 입력하면 점수를 자동 계산(VBA-Python 브릿지)
③
EPSS·KEV 자동 조회
실제 악용 확률과 악용 확인 목록을 자동으로 조회
④
유사 사례 검색
과거 확정 사례 중 비슷한 것을 찾아 참고 자료로 제시
핵심 원리
Exact 매칭 우선 실패 시 임베딩 기반 Semantic 매칭으로 후보 제시
임베딩 방식
로컬 오픈소스 모델(BGE-M3)이 기본값 — 보안 고려 필요 시 OpenAI 등 상용 임베딩으로 전환 가능
03어떻게 동작하는가
1
모니터링 결과 입력
취약점 모니터링에서 찾은 CVE 정보를 분석 대장으로 가져온다
2
자산 매칭
Vendor/Product/Version을 Config(SBOM)와 대조해 해당 자산을 찾는다
3
점수·확률 조회
CVSS를 계산하고 EPSS·KEV를 함께 조회한다
4
TARA 연계 판단
기존 위협시나리오와 일치하는지 확인해 재사용하거나 재수행한다
5
처리 방향 결정
VEX 상태·위험처리·담당자·기한을 확정해 대장에 기록한다
04SBOM 자산유형별 처리 기준
자산 유형
CVE 매칭 가능성
TARA 연계
자체개발
거의 없음 — 비공개라 CVE 자체가 안 붙음
이미 분석된 자산이면 그대로 재사용 가능
외주조달
상위 벤더명만으론 부족 — 서브컴포넌트까지 풀어야 매칭 작동
서브컴포넌트 단위로 풀어야 유효(FSIA/CSIA로 확보)
오픈소스(OSS)
높음 — 벤더/제품명이 공개적으로 알려짐
자체개발과 동일 기준으로 연계 가능
Config는 자체개발 + 외주 + 오픈소스를 포함한 전체 SBOM으로 채운다 — 다만 실제 매칭 히트는 구조적으로 외주·오픈소스 쪽 위주로 나온다.
05TARA 연계 — 재사용 vs 재계산
경우 A — 기존 공격경로와 일치
기존 TARA 값을 그대로 복사
위협시나리오ID·AFR·Impact를 재계산 없이 그대로 가져온다. 가장 빠르고 TARA와의 정합성이 자동 보장된다.
경우 B — 새로운 공격경로
새로 등록하고 재계산 + 피드백
새 위협시나리오를 등록하고 같은 방법으로 다시 계산한다. TARA DB에도 피드백해 다음 리비전에 반영한다.
06OEM-Tier 구조에서의 한계
Tier가 TARA 이행만 담당하는 구조에서는, 위협시나리오·AFR은 Tier가 자체적으로 채울 수 있지만 Impact(차량 레벨 피해)는 Tier 혼자 완결할 수 없다. 이 경계는 FSIA/CSIA 인터페이스 어그리먼트로 공식화해, 언제·어떤 형식으로 OEM에 이관하는지 명확히 해야 한다.
07기대 효과
자산 판단 시간 단축
이름이 완전히 같지 않아도 유사도로 자동 후보를 찾는다
위험도 판단이 다면화
CVSS뿐 아니라 실제 악용 확률·확인 이력까지 함께 본다
TARA와 이중 작업 없음
이미 분석된 위협은 재사용하고, 새 위협은 자동으로 피드백된다
보안을 지키며 자동화
민감한 자산 정보를 외부로 보내지 않는 로컬 임베딩이 기본값이다
08유의할 점
  • 벤더/제품명이 다른 언어·표기로 섞이면 Exact 매칭이 실패할 수 있어, Semantic 매칭 결과는 사람이 확인해야 한다
  • 임베딩 방식(로컬/상용)을 중간에 바꾸면 좌표계가 달라져, 벡터DB를 비우고 전체 재임베딩해야 한다
  • Impact 판정을 Tier 혼자 완결할 수 없는 구조에서는 OEM 이관 경로를 사전에 합의해 둬야 한다
