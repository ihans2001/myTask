IHANS-PRO-2026-028 2026-09-10 가이드

프로젝트 자체 심사(제1자 심사)

A-SPICE 4.0 기반으로 개발한 프로세스 심사 템플릿을 활용한다. 제2자·제3자 심사(Audit)에 대비한 자체 자율 심사(제1자 심사)에 쓰며, 연구원의 프로세스 지식 함양에도 기여한다.
BP/GP 기반 NPLF 평가 CL/PA 자동 집계 증적파일 자동 목록화
01왜 필요한가
제2자·제3자 심사 대비 필요
고객·인증기관의 실제 심사 전에 미리 점검해 볼 수단이 필요하다
프로세스 지식이 실무에 스며들기 어려움
프로세스 기준을 문서로만 알고 있으면 실제 개발에 반영되기 어렵다
증적 자료를 매번 찾아 헤맴
심사 때마다 객관적 증거(OE) 파일을 어디에 뒀는지 새로 찾아야 한다
평가 결과가 프로세스별로 흩어짐
여러 프로세스를 함께 보지 않으면 프로젝트 전체 성숙도를 가늠하기 어렵다
02무엇을 만드는가
①
BP/GP 기반 NPLF 평가
Base/Generic Practice별로 N/P/L/F(또는 6단계) 척도로 심사자가 직접 평가한다
②
CL·PA 자동 집계
개별 평가를 Process Attribute(PA)와 Capability Level(CL)로 자동 집계한다
③
다중 프로세스 통합 관리
ACQ.4/SPL.2/MAN.3/SUP.1 등 여러 프로세스의 CL 프로파일을 한 시트에서 관리한다
④
증적파일 자동 목록화
기준 폴더(하위 폴더 포함)에서 지정 기간 내 파일을 자동으로 찾아 목록화한다
핵심 원리
적색 텍스트 셀은 수식으로 자동 갱신되어 수동 편집 불가
평가 척도
4단계(N/P/L/F) 6단계(N/P-/P+/L-/L+/F) 중 선택 가능
03어떻게 동작하는가
1
심사 범위 설정
대상 프로세스와 목표 CL(예: SPL.2, CL3)을 지정한다
2
BP/GP 평가
AuditPad에서 각 BP/GP 항목에 Rating과 Notes, OE statements를 기록한다
3
증적파일 자동 목록화
AuditFileCheck가 기준 폴더에서 지정 기간의 증적 파일을 자동으로 찾는다
4
CL/PA 자동 집계
개별 BP/GP 평가가 ProcessInstance 시트에서 PA·CL로 자동 집계된다
5
심사 리포트 생성
Report 시트에 프로세스별 평가 결과와 일자가 정리되어 출력된다
04심사 유형 비교
구분
제1자 심사 (자체, 이번 문서)
제2자·제3자 심사
심사 주체
프로젝트/조직 내부
고객사 또는 인증기관
목적
사전 점검, 프로세스 지식 함양
공식 인증, 계약 요건 충족
빈도
필요 시 수시로 반복 가능
정해진 일정에 따라 제한적으로 수행
제1자 심사에서 낮게 평가된 항목을 미리 보완해두면, 제2자·제3자 심사에서의 리스크를 줄일 수 있다.
05Before / After
이전 — 심사 임박해서 준비
그때그때 증적을 찾아 대응
실제 심사가 닥쳐서야 증적을 찾고 프로세스 이해도를 점검하기 시작했다.
현재 — 상시 자체 심사 체계
미리 점검하고 미비점을 보완
템플릿으로 미리 자체 심사를 수행해두어, 실제 심사 전에 미비점을 보완할 수 있다.
06기대 효과
심사 리스크 사전 관리
제2자·제3자 심사 전에 미비 항목을 미리 파악하고 보완한다
프로세스 지식 함양
연구원이 BP/GP를 직접 평가하며 프로세스 기준을 체득한다
증적 관리 효율화
증적파일을 자동으로 목록화해 심사 준비 시간을 줄인다
위기관리에도 기여
자율 심사로 드러난 리스크의 조기 발견이 전사 위기관리 문화에도 도움이 될 수 있다
07유의할 점
  • ProcessInstance 시트의 적색 텍스트(CL/PA 값)는 수식으로 자동 갱신되므로 직접 수정하면 안 되며, BP/GP 평가(Rating)만 입력해야 한다
  • 평가 척도(4단계/6단계)는 조직 기준에 맞춰 사전에 하나로 통일해야 프로세스 간 비교가 가능하다
  • 본 템플릿은 셀프 심사(제1자 심사) 도구이며 제2자·제3자 심사를 대체하지 않는다 — 전사 위기관리체계의 "조기 발견" 원칙과 같은 방향에서 보조적으로 활용한다
