프로젝트 일정 아웃룩 캘린더 연동

프로세스 테일러링(문서번호 001)으로 수립된 일정을 아웃룩 캘린더에 자동 등록한다. 일정이 갱신되면 기존 등록분을 자동 삭제하고, 오늘+근무일 3일 기준 주요 태스크를 자동·수동으로 모니터링한다.
VBA-Outlook COM 연동 동기화 제어(삭제/유지/제외) 근무일 3일 자동 모니터링
01왜 필요한가
수립된 일정이 캘린더에 없음
프로세스 테일러링으로 만든 일정표가 엑셀에만 있으면 놓치기 쉽다
일정이 자주 갱신됨
계획이 바뀔 때마다 기존 캘린더 일정을 수동으로 지우고 다시 넣기는 번거롭다
표준 프로세스가 70개+ 태스크
단위 업무가 많아 오늘 무엇을 해야 하는지 한눈에 파악하기 어렵다
프로젝트별 현황을 매번 찾아봐야 함
여러 프로젝트를 동시에 다루면 오늘 할 일을 놓치기 쉽다
02무엇을 만드는가
①
일정 자동 등록
스케줄 시트의 계획 시작/종료일을 아웃룩 캘린더에 자동으로 등록한다
②
갱신 시 자동 삭제·재생성
"동기화(기존삭제)" 설정 시 이전 등록 일정을 지우고 최신 일정으로 재등록한다
③
알림 자동 설정
시작 1주 전·전날, 종료 3일 후 지연확인까지 알림 일정을 자동 생성한다
④
근무일 3일 모니터링
오늘부터 영업일 기준 3일치 태스크를 자동 분류해 표출한다
핵심 원리
각 일정 본문에 [ROW:n] 태그를 심어 같은 행의 일정만 정확히 찾아 삭제
동기화 제어
N열에서 행별로 "동기화(기존삭제) / 동기화(기존유지) / 제외" 선택
03어떻게 동작하는가
1
프로세스 테일러링
문서번호 001에서 표준 프로세스 70개+ 단위 태스크로 일정표를 자동 생성한다
2
동기화 설정 선택
스케줄 시트 N열에서 행별로 기존삭제/기존유지/제외를 선택한다
3
아웃룩 일정 등록
SyncScheduleToOutlook이 계획 시작/종료일과 알림 일정을 캘린더에 생성한다
4
자동·수동 모니터링
아웃룩 시작 시 자동으로, 또는 필요할 때 버튼 클릭으로 오늘+3일 현황을 확인한다
5
키워드 일괄 정리
프로젝트가 끝나면 프로젝트명 키워드로 관련 일정을 한 번에 삭제한다
04모듈별 역할
구분
Schedule_To_Outlook / mCalendarDelete
mTodayCheck_PJT
실행 위치
Excel VBA (전자) / Outlook VBA (후자)
Outlook 자체 VBA 프로젝트
역할
일정 등록·자동삭제·재생성 / 키워드로 일정 일괄 삭제
근무일 3일 현황 자동·수동 모니터링
트리거
매크로 버튼 실행
Outlook 시작 시 자동 또는 버튼 클릭
mTodayCheck_PJT는 Excel이 아니라 Outlook 자체 VBA 프로젝트에 설치해야 하며, ThisOutlookSession에 Application_Startup을 등록하면 아웃룩을 열 때마다 자동으로 표출된다.
05Before / After
이전 — 엑셀 일정표만 확인
캘린더 알림 없이 오늘 할 일을 놓침
수립된 일정이 엑셀에만 있어, 캘린더 알림 없이는 오늘 할 일을 놓치기 쉽다.
현재 — 캘린더 자동 등록·모니터링
아웃룩을 열 때마다 오늘+3일 자동 표출
일정이 캘린더에 자동 등록되고, 오늘+3일 주요 태스크가 아웃룩을 열 때마다 자동으로 보인다.
06기대 효과
일정 누락 방지
계획된 일정이 캘린더 알림으로 자동 챙겨진다
갱신 부담 최소화
일정이 바뀌어도 기존 등록분을 자동으로 지우고 다시 채운다
오늘 할 일 즉시 확인
근무일 3일 기준으로 무엇을 해야 하는지 바로 알 수 있다
다중 프로젝트 대응
프로젝트별 일정을 키워드로 구분해 관리·정리할 수 있다
07유의할 점
  • 재동기화 시 "동기화(기존삭제)"를 선택한 행만 이전 일정이 지워지고 재생성된다 — "기존유지"는 중복 등록될 수 있어 주의한다
  • mTodayCheck_PJT는 Outlook 자체 VBA 프로젝트에 설치해야 동작하며, 매크로 보안 설정에서 실행이 허용되어 있어야 한다
  • 근무일 3일 기준 산정은 월~금만 영업일로 계산하므로, 공휴일은 별도로 고려되지 않는다
