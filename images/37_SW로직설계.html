SW 설계로직 개발 (LLM 기반)

레거시 코드와 설계요구조건을 바탕으로 LLM이 SW 로직·테스트케이스(draft)·플로우차트·MBD 설계가이드를 함께 도출한다. 최초개발과 파생개발/유지보수를 하나의 파이프라인으로 지원한다.
Quad-Route 요구조건 입력 3대 옵션(성능/가독성/안전성) 레거시 코드 1:1 교체
01왜 필요한가
요구조건마다 입력 형식이 제각각
PDF/워드/엑셀/구두 지시 등 요구조건이 다양한 형태로 들어와 정형화가 필요하다
설계 옵션을 매번 새로 고민
성능/가독성/안전성 중 무엇을 우선할지 매번 처음부터 판단해야 한다
파생개발에서 기존 코드가 무시됨
유지보수·파생개발인데도 새로 작성하듯 설계하면 기존 함수와 어긋난다
검증 업무량을 미리 가늠하기 어려움
설계 단계에서 테스트 범위를 가늠할 자료가 없으면 이후 검증 계획을 세우기 어렵다
02무엇을 만드는가
①
Quad-Route 요구조건 입력
PDF·TXT·엑셀 셀 참조·InputBox 4가지 방식으로 요구조건을 수집해 SSoT로 정제한다
②
LLM 프롬프트 구조화
정제된 요구조건과 (파생개발 시) 레거시 코드를 묶어 구조화된 프롬프트로 합성한다
③
3대 옵션 SW 로직 설계
성능/자원 최적화형·가독성/유지보수형·안전성/예외처리 강화형 중 단일 또는 복수 선택해 최종 로직을 설계한다
④
TC(draft)+플로우차트+MBD 가이드 동시 산출
설계와 함께 테스트케이스 초안, 조건문 강조 플로우차트, Ascet/Simulink 설계가이드(C코드 방식)를 함께 만든다
핵심 원리
파생개발/유지보수는 진입 함수명을 레거시 원본으로 강제해 "새로 작성"이 아닌 "기존 함수 수정"으로 프롬프트 재구성
검증 이력
이스케이프 파싱 오염·REQ-ID의 C식별자 변환·헤더-실제 함수명 불일치 등 실행 로그 기반 결함을 진단·수정해 안정화
03어떻게 동작하는가
1
요구조건 수집
PDF/TXT/엑셀 셀 참조/InputBox 중 하나로 설계요구조건을 입력한다
2
(파생개발 시) 레거시 코드 등록
특정 함수를 지정하면 legacy_code.json으로 저장해 프롬프트에 함께 포함한다
3
프롬프트 구조화
요구조건(+레거시 코드)을 묶어 LLM에 전달할 구조화 프롬프트를 합성한다
4
3대 옵션 설계 도출
성능/가독성/안전성 옵션을 LLM이 각각 도출하고, 선택·병합해 최종 로직을 확정한다
5
TC(draft)·플로우차트·MBD 가이드 생성
확정된 로직을 바탕으로 테스트케이스 초안과 시각화·MBD 산출물을 동시에 만든다
04최초 개발 vs 파생개발/유지보수
구분
최초 개발
파생개발 / 유지보수
입력
설계요구조건만
설계요구조건 + 레거시 코드
LLM 프롬프트
요구조건 기반 신규 설계 지시
"기존 함수 수정"으로 재구성, 진입 함수명 원본 고정
결과 비교
—
Legacy_Compatibility 열에 유지/변경 내역 기록
3대 옵션(성능/가독성/안전성)은 택일뿐 아니라 복수 선택 후 조건부 병합도 가능하며, 그 결과는 병합 전용 브릿지가 별도로 합성한다.
05Before / After
이전 — 요구조건마다 수작업 설계
테스트 범위는 별도로 재산정
형식이 제각각인 요구조건을 사람이 해석해 로직을 설계하고, 테스트 범위는 별도로 다시 산정해야 했다.
현재 — 입력~설계~TC까지 한 파이프라인
옵션별 로직과 TC를 한 번에
요구조건을 넣으면 옵션별 로직과 테스트케이스 초안, 플로우차트, MBD 가이드까지 한 번에 나온다.
06기대 효과
입력 방식 유연화
PDF/TXT/엑셀/구두 지시 어떤 형태든 같은 파이프라인으로 처리한다
설계 관점 선택 가능
성능/가독성/안전성 중 프로젝트 상황에 맞는 옵션을 고를 수 있다
레거시 호환성 확보
파생개발에서 기존 함수를 그대로 유지하며 변경 내역만 명확히 남긴다
검증 업무 사전 산정
설계 단계의 TC(draft)로 이후 테스트케이스 설계·비교의 출발점을 마련한다
07유의할 점
  • TC(draft)는 설계 검증 업무량을 가늠하기 위한 초안이며, 실제 SW 테스트케이스 설계 시 다시 비교·보완해야 한다
  • 레거시 코드를 반영한 파생개발에서는 진입 함수명이 레거시 원본 그대로 강제되므로, 함수명을 바꾸는 리팩터링과는 함께 쓸 수 없다
  • 요구사항이 갈라지는 특정 분기의 색상 강조는 아직 근거 데이터(요구사항↔코드 매핑)가 준비되지 않아 유보되어 있다
