IHANS-PRO-2026-003 2026-09-09 제안서

제어기 사이버보안 위협분석
(Full TARA) 자동화

국제표준(ISO/SAE 21434) 방식의 위협분석 6단계를 하나의 워크북 안에서 처음부터 끝까지 수행한다. 자산 정의부터 위험 처리, 근거 문서화까지 — 별도 서버 없이도 완결된다.
6단계 표준 프로세스 6종 등급 산정 모델 8대 보안 속성
01왜 필요한가
매번 새로 만드는 분석 문서
표준 양식 없이 제어기마다 위협분석 문서를 처음부터 다시 작성한다
평가 모델마다 결과가 제각각
고객·조직마다 요구하는 등급 산정 방식이 달라 같은 위협을 여러 번 재평가해야 한다
방대한 문서화 부담
심사·인증에 필요한 근거 자료를 별도로 정리하느라 과다한 시간이 소요된다
효과를 숫자로 보여주기 어려움
보안 조치를 적용하기 전과 후의 위험이 얼마나 줄었는지 정량적으로 설명하기 힘들다
02무엇을 만드는가
①
통합 TARA 워크북
아이템 정의부터 목표·근거 문서까지 전 과정을 하나의 파일에 기록
②
6단계 표준 입력 양식
국제표준 절차를 그대로 따라가며 채워 넣는 템플릿
③
위험처리 전/후 비교표
보안 조치 적용 전·후의 위험 등급 변화를 자동으로 정리
④
검증 체크리스트
단계별 작성 완료 여부를 스스로 점검·승인하는 표
자동화되는 5가지 작업
위협 시나리오 문장 자동 생성 공격 트리 구조 자동 작성 공격 가능성 등급 자동 계산 등급 모델간 자동 상호 변환 보안 목표·근거 자동 분류
이용 방식
단독 실행 가능(별도 서버 불필요) AI 보조는 선택 기능
036단계 분석 흐름
1
아이템 정의
분석 대상 제어기의 기능·구성요소·통신 인터페이스를 정리한다
2
자산 · 손상 시나리오
지켜야 할 자산을 정하고, 침해됐을 때 발생할 피해의 등급을 평가한다
3
위협 시나리오
8가지 공격 유형(스푸핑·변조·재전송 등) 기준으로 위협을 서술한다
4
공격 가능성 등급
공격 트리를 구성해 실제 공격이 얼마나 쉬운지 등급을 매긴다
5
위험 처리
등급에 따라 조치 여부를 결정하고, 적용 전·후 위험을 비교한다
6
목표 · 근거 문서화
결정된 조치를 보안 목표와 근거(클레임) 문서로 정리한다
04공격 가능성 등급 — 6종 산정 모델
HMC4
2단계 구조의 자체 정의 모델
HEAVENS4
HMC4와 동일한 2단계 구조를 적용하는 모델
ISO18045_FULL4
소요시간·전문성·지식·기회·장비 5요소를 모두 반영하는 완전판
ISO18045_DIM4
소요시간 항목을 제외한 4요소 축소판
FTS_SUM4
2단계 요소를 합산하는 방식
FTS_MULTI4
2단계 요소를 곱산하는 방식
Correlation 자동 변환 — 6개 모델 중 하나만 완성해도, 나머지 5개 모델의 등급을 같은 데이터에서 자동으로 함께 산출한다. 고객·조직마다 요구 모델이 달라도 다시 평가할 필요가 없다.

06기대 효과
국제표준 방식 그대로 적용
별도 해석 없이 표준 절차를 따라가는 것만으로 분석이 완성된다
평가 모델 재작업 제거
하나만 작성해도 6개 모델의 결과를 동시에 확보한다
조치 효과를 숫자로 증명
보안 조치 전·후 위험 등급 변화가 비교표로 자동 정리된다
심사 대응 자료 즉시 확보
워크북 자체가 검증 체크리스트를 포함한 근거 문서가 된다
07유의할 점
이 워크북은 단독으로 완결 동작한다 — 등급 산정과 상호 변환 등 핵심 기능은 외부 서버나 AI 없이도 100% 동작한다. AI(LLM)는 시나리오 문장을 다듬는 등 선택적인 보조 기능일 뿐이며, 보안이 우려되는 환경에서는 AI 보조 기능을 끄고 완전히 폐쇄된 환경에서 사용할 수 있다.
