KIPRIS 특허조사 및 분석 자동화

정부 무료 API인 KIPRIS Plus를 활용해 특허 조사·분석 업무를 자동화한다. 특허조직은 조사·분류 역할에, 연구조직은 분석에 집중하는 체계적인 업무 분담을 만든다.
VBA-Python 브릿지 4개 연산자 로컬 검색식 3단계 예산배분 파이프라인
01왜 필요한가
반복적인 대량 조사 작업
특허조사는 키워드별로 대량의 결과를 훑어야 하는 반복 작업이라 수작업으로는 비효율적이다
상용 툴은 고가
WIPSON 등 상용 서비스는 일 5,320원 × 365일 = 연 1,941,800원 수준의 비용이 든다
사전 교육 없이 쓰기 어려움
WIPSON은 편의기능이 풍부하지만, 연구원에게 개방해도 교육 없이는 활용이 어렵다
조사와 분석 역할이 미분리
특허조직과 연구조직의 역할이 명확히 나뉘지 않아 체계적인 업무 수행이 어렵다
02무엇을 만드는가
①
특허 기본정보 검색
키워드로 제목·초록·출원인·IPC 등 서지정보를 대량으로 확보
②
무료 로컬 필터링
4개 연산자(괄호>NOT>AND>OR) 검색식으로 API 예산 없이 정밀화
③
청구항·전문 자동 확보
선별된 특허만 청구항 텍스트와 전문 PDF를 확보
④
엑셀 기반 조사·분류
조사된 특허는 엑셀 시트로 다운로드되어 그대로 조사·분류 작업에 활용
핵심 원리
예산이 드는 단계는 필터링 이후에만 실행 검색 → 필터링(0원) → 전문조회 순서 고정
검증 방법
무료 KIPRIS API로 성능 검증 후 필요시 확장 검토
03어떻게 동작하는가
1
기본정보 검색
searchPatent → patentSearchList, 키워드당 1~수 회 API 호출로 서지정보 확보
2
특허조사·유효특허 식별
괄호>NOT>AND>OR 우선순위의 검색식으로 행을 필터링, API 예산 0회 소모
3
풀텍스트 정보 검색
필터링된 특허만 대상으로 청구항·전문 PDF 확보, 건당 2~3회 소모
04비용 비교
구분
KIPRIS API (무료)
WIPSON (상용)
비용
월 1,000회 무료 한도
일 5,320원 × 365일 = 연 1,941,800원
사용 난이도
자동화 스크립트로 직접 구현
편의기능 풍부하나 사전 교육 필요
확장성
VBA-Python 브릿지로 자체 커스터마이즈
벤더 제공 기능 범위 내로 제한
무료 API로 기능·성능을 먼저 검증하고, 예산이 부족해지면 그때 유료 확장을 검토하는 순서로 접근한다.
05Before / After
이전 — 조사와 분석이 미분리
역할이 섞여 비효율 발생
특허조직과 연구조직이 조사와 분석을 명확히 나누지 못해 업무가 섞이고 체계적으로 진행되기 어려웠다.
이후 — KIPRIS 자동화로 역할 분리
조사와 분석을 체계적으로 분담
특허조직은 조사·분류에 집중하고, 연구조직은 분석에 집중하는 역할 분담이 가능해진다.
06기대 효과
비용 절감
연 194만원 상당의 상용 서비스 없이 무료 API로 우선 검증한다
예산 낭비 방지
필터링을 먼저 거쳐 예산이 큰 전문조회 호출을 최소화한다
역할 분리
조사는 특허조직, 분석은 연구조직으로 업무가 체계화된다
정확도 보장
검증된 로컬 집합연산으로 AND/OR 조합 결과의 정확도를 보장한다
07유의할 점
  • KIPRIS 웹다운로드 자동화는 robots.txt로 명시적으로 금지되어 있어 API 경로만 사용한다
  • year 파라미터는 실제 연도가 아닌 0~10 사이 "N년차" 정수만 유효하다
  • 잔여 API 예산은 API로 조회할 수 없어, 로컬 카운터와 마이페이지를 정기적으로 수동 대조해야 한다
