IHANS-PRO-2026-022 2026-09-10 가이드

PDF 파싱 문서 변환 자동화

고객·협력사에서 PDF로 입수되는 자료를 후속 업무에 맞는 형태(워드 / RAG용 JSON)로 자동 변환한다. 병합셀 표는 변환본과 원본 이미지를 함께 넣어 대조하고, 이미지는 LLM으로 설명을 생성해 RAG에 활용한다.
pdfplumber + PyMuPDF + python-docx Vision LLM 이미지 설명 기준 기반 품질평가 리포트
01왜 필요한가
PDF로만 입수되는 자료가 많음
고객·협력사 자료는 PDF로 전달되는 경우가 많아 후속 업무에 그대로 쓰기 어렵다
병합셀 표는 변환이 불완전함
병합셀이 많이 쓰인 표는 워드로 변환해도 원본과 완벽히 같지 않을 때가 있다
이미지 정보가 텍스트에서 빠짐
RAG 검색에 활용하려면 이미지 안의 내용도 텍스트로 남아 있어야 한다
변환 품질을 확인할 방법이 없음
변환이 잘 됐는지 매번 원본과 눈으로 대조하기는 번거롭다
02무엇을 만드는가
①
PDF → 워드 변환
본문·표·이미지를 원본 등장 순서 그대로 워드 문서에 삽입한다
②
표 변환 + 원본 이미지 병기
편집 가능한 표(native)와 원본 캡처 이미지(image)를 함께 넣어 바로 대조할 수 있다
③
이미지 LLM 설명 생성
Vision LLM이 이미지 내용을 설명 문단으로 변환해 RAG에서 검색 가능하게 만든다
④
품질평가 리포트
텍스트 재현율·표 셀 일치율·이미지 무결성을 기준별로 채점해 텍스트 문서로 제공한다
핵심 원리
provenance(extracted / ai_generated)로 원문과 AI 생성 설명을 절대 혼동하지 않음
품질 기준
텍스트 재현율·정밀도 98%↑ 표 셀 재현율 100% 이미지 무결성 100%
03어떻게 동작하는가
1
텍스트/표/이미지 추출
pdfplumber+PyMuPDF로 본문·표 위치·내장 이미지를 추출한다
2
워드 문서 생성
등장 순서대로 워드에 삽입하고, 표는 native+image로 함께 넣는다
3
목차 자동 삽입
제목 계층을 인식해 워드 네이티브 목차(TOC)를 자동 생성한다
4
이미지 LLM 설명(RAG용)
Vision LLM이 이미지를 설명 문단으로 바꿔 JSON에 담는다
5
품질평가 리포트 생성
기준별로 채점한 결과를 텍스트 문서로 정리해 제공한다
04버전별 비교
구분
v1 (basic) / v2 (toc)
v3 (rag)
주 산출물
워드 문서 (v2는 목차 포함)
RAG용 JSON (+워드 보조 출력)
표 처리
native / image / both 선택
마크다운 + 원본 rows 이중표현
이미지 처리
원본 그대로 추출·삽입
Vision LLM으로 설명 문단 생성
용도
사람이 읽는 최종 문서
RAG 파이프라인의 검색·인용 자료
v3는 이미지 바이트 해시 기반 캐시로 같은 이미지를 다시 호출하지 않아 LLM 비용을 절감한다.
05Before / After
이전 — PDF 그대로 활용
매번 수작업으로 옮겨 적음
고객·협력사 PDF 자료를 후속 업무에 쓰려면 매번 수작업으로 옮겨 적어야 했다.
현재 — 목적별 자동 변환
워드와 RAG용 JSON을 각각 자동 생성
사람이 읽을 워드 문서와 RAG가 검색할 JSON을 각각의 목적에 맞게 자동으로 만든다.
06기대 효과
후속 업무 활용성 향상
PDF 내용을 워드나 RAG용 JSON으로 즉시 활용할 수 있다
표 변환 신뢰성 확보
병합셀 표도 원본 이미지와 나란히 두어 눈으로 바로 대조한다
이미지까지 검색 가능
LLM 설명으로 이미지 정보도 RAG 검색 대상에 포함된다
품질을 한 번에 확인
기준별 채점 리포트로 변환 결과를 즉시 점검할 수 있다
07유의할 점
  • provenance가 ai_generated인 이미지 설명은 원문이 아니므로 인용 시 구분해서 표기해야 한다
  • table-mode=image에서는 표 내용이 텍스트로 남지 않아 재현율(T-01)이 낮게 나오는 것이 정상이다 — 그림 개수(I-01)와 육안 확인으로 판단한다
  • 워드 목차(TOC)는 자동 삽입되지만 Word에서 F9(필드 업데이트)를 눌러야 실제 목차 내용이 채워진다
