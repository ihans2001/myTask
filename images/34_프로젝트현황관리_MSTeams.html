IHANS-PRO-2026-034 2026-09-10 가이드

MS Teams 채널 대화 리스크 분석·보고

메일·JIRA 현황관리와 같은 목적으로, Teams 채널의 대화를 주기적으로 또는 필요 시점에 분석해 요약·톤앤매너·리스크(변화 추이 포함)를 자동 기록한다. Teams API와 수동 복사-붙여넣기 두 가지 방식을 모두 지원한다.
LLM 기반 톤앤매너·리스크 분석 변경 감지 시에만 LLM 호출 Confluence 타임라인 누적 게시
01왜 필요한가
대화가 여러 채널에 흩어져 있음
고객·협력사 채널마다 대화를 따로 확인해야 한다
변화만 짚어내기 어려움
매주 전체 대화를 다시 읽으면 실제로 뭐가 달라졌는지 찾기 어렵다
소통 분위기까지는 파악 못함
단순 진행상황 요약만으로는 갈등이나 긴장 같은 신호를 놓치기 쉽다
Teams API를 못 쓰는 환경도 있음
권한·인증 문제로 API 연동이 막힌 조직도 대비해야 한다
02무엇을 만드는가
①
채널별 대화 수집
Teams API 또는 수동 복사-붙여넣기로 채널(하위 채널 포함)의 대화를 수집한다
②
변경 감지(콘텐츠 해시)
주제별 콘텐츠 해시로 직전 대비 신규/변경/삭제를 판정하고, 변경 없는 주제는 LLM 호출을 건너뛴다
③
LLM 요약·톤앤매너·리스크 분석
변경된 주제만 골라 주간 요약, 소통 톤앤매너, 리스크 등급·사유를 LLM으로 추출한다
④
Confluence·엑셀·메일 3중 기록
분석 결과를 Confluence 타임라인에 누적 게시하고, 엑셀 리포트로 정리해 지정 수신자에게 메일로 보낸다
핵심 원리
주제(Topic)마다 대화+답글+첨부파일을 합쳐 SHA-256 해시 계산, 동일하면 UNCHANGED로 LLM 재호출 차단
발송 경로
1차 Outlook 데스크톱(COM) 시도 → 실패 시 Office 365 SMTP로 자동 전환
03어떻게 동작하는가
1
대화 수집(2가지 방식)
Teams API 또는 GUI로 복사-붙여넣기한 대화를 raw_text로 수집한다
2
구조화 파싱
LLM이 비정형 대화를 주제·스레드·답글·첨부파일 구조의 JSON으로 정규화한다
3
변경 감지
직전 스냅샷과 주제별 해시를 비교해 ADDED/MODIFIED/UNCHANGED/DELETED를 판정한다
4
LLM 리스크 분석
변경된 주제만 요약·톤앤매너·리스크 등급·사유를 분석한다 (UNCHANGED는 캐시 재사용)
5
게시·리포트·발송
Confluence 타임라인 게시, 엑셀 리포트 생성, 메일 자동 발송을 순서대로 수행한다
042가지 수집 방식 비교
구분
① Teams API 연동
② 수동 복사-붙여넣기 (GUI)
전제조건
Teams API 권한·인증 필요
별도 인증 없이 사람이 직접 붙여넣기
구현 상태
설계상 자리 마련 (ingestion_mode 필드)
manual_input_gui.py로 구현 완료
용도
API 사용 가능한 조직의 기본 경로
API 연동이 막힌 경우의 대체 경로
ingestion_mode 값으로 두 경로를 구분하며, 이후 파이프라인(LLM 파싱~메일발송)은 동일하게 재사용된다.
05Before / After
이전 — 채널마다 수작업 확인
사람이 리스크를 직접 판단
여러 채널의 대화를 각자 열어 읽고, 무엇이 리스크인지 사람이 판단해야 했다.
현재 — 변경분만 자동 분석
3중 기록으로 자동 정리
바뀐 주제만 LLM이 요약·톤앤매너·리스크로 분석해 Confluence·엑셀·메일로 자동 기록한다.
06기대 효과
LLM 비용 절감
변경 없는 주제는 캐시를 재사용해 불필요한 API 호출을 막는다
소통 리스크 조기 포착
진행상황뿐 아니라 톤앤매너까지 분석해 갈등·긴장 신호를 놓치지 않는다
이력 추적 가능
주제별 history가 누적되어 여러 주에 걸친 변화 추이를 볼 수 있다
API 유무에 관계없이 동작
Teams API가 막혀도 수동 입력 GUI로 동일한 파이프라인을 쓸 수 있다
07유의할 점
  • 현재 첨부에는 수동 복사-붙여넣기(GUI) 경로만 실제 코드로 포함되어 있으며, Teams API 연동은 ingestion_mode 필드로 자리만 마련된 상태다
  • 메일 발송은 1차로 Windows Outlook 데스크톱(COM)을 시도하고, 실패하면 Office 365 SMTP로 자동 전환한다
  • LLM 분석 결과가 캐시(is_cached=true)로 표시되면 이번 주 새로 분석한 것이 아니라 직전 결과를 재사용한 것이다
