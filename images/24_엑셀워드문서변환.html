IHANS-PRO-2026-024 2026-09-10 제안서

엑셀→워드 문서 변환 자동화

config 파일 하나로 시트-챕터 매핑을 정의하고, main 실행 한 번으로 엑셀 워크시트를 워드 보고서로 변환한다. 제공 가능한 부분만 선택해 담아 노하우 유출도 방지한다.
config 기반 선언적 설정 병합 헤더 자동 확장 북마크 3개로 최소화
01왜 필요한가
반복적 수작업과 오류
시트 수가 많을수록(과제당 15~20개) 복사·붙여넣기가 반복되고 누락·서식붕괴가 발생한다
북마크 방식의 구조적 취약성
문서를 편집하다 보면 북마크가 소리 없이 사라져 시트가 통째로 누락될 수 있다
서식 재현이 어려움
코드로 표를 새로 만들면 음영·테두리·폰트 같은 서식이 라이브러리 기본값으로 대체된다
병합 셀 헤더 처리 누락
위험도처럼 상위 개념을 병합 셀로 묶은 헤더는 단순 열 지정만으로는 제대로 인식되지 않는다
02무엇을 만드는가
①
config 기반 시트-챕터 매핑
config.py 하나로 시트별 규칙과 문서 구조를 선언적으로 관리한다
②
병합 헤더 자동 확장
지정한 열이 병합 범위에 속하면 관련 열 전체를 자동으로 포함한다
③
표 서식 복제
워드 템플릿의 모범 표 서식(음영·테두리·폰트)을 그대로 복제해 표를 생성한다
④
선택적 제공 범위 지정
config에서 시트/열을 선택해, 제공 가능한 부분만 워드로 변환한다
핵심 원리
설정(config)과 실행 엔진(excel_reader/word_writer/main)을 분리
북마크 최소화
표지 제목·목차·모범 표 서식 3개로 관리 포인트 축소
03어떻게 동작하는가
1
config.py 설정
엑셀/템플릿 경로, 시트별 규칙(SheetConfig), 챕터 목차 골격을 정의한다
2
엑셀 읽기
excel_reader.py가 시트별 규칙에 따라 헤더·데이터를 추출하고 병합 헤더를 자동 확장한다
3
종료·제외 판정
순환열(loop_col) 공백 여부와 skip 조건으로 데이터 종료·행 제외를 판정한다
4
워드 생성
word_writer.py가 챕터 헤딩과 표를 모범 표 서식으로 복제해 생성한다
5
제목·목차 반영
문서 제목을 표지에 반영하고 TOC 필드를 삽입해 저장한다
04As-Is vs To-Be
구분
As-Is (수작업)
To-Be (자동화)
변환 방식
시트별 수작업 복사·붙여넣기
config 설정 + 1회 실행 스크립트
예외 처리
매번 개별 수정
SheetConfig 파라미터로 선언적 처리
서식 일관성
작성자별 편차 발생
모범 표 1개를 전 챕터에 복제 적용
구조 변경 대응
표 위치마다 북마크 재배치 필요
챕터 경로(config)만 수정, 북마크 불변
20개 워크시트, 4단계 챕터 구조로 실제 검증했으며, 표 서식(음영 D9D9D9 등)까지 정상 복제됨을 확인했다.
05Before / After
이전 — 전체 문서 그대로 제출
노하우 유출 위험
엔지니어링 산출물을 통째로 제출하면 당사 노하우가 그대로 유출될 위험이 있다.
현재 — 제공 범위만 선택 변환
필요한 부분만 문서화
config에서 제공 가능한 시트/열만 선택해, 필요한 부분만 워드 문서로 변환해 제출한다.
06기대 효과
변환 시간 단축
수작업 복사·붙여넣기를 스크립트 실행 수 초로 대체한다
인수인계 리스크 감소
변환 규칙이 config 파일로 문서화되어 개인 기억에 의존하지 않는다
시각적 일관성 확보
모범 표 서식을 그대로 복제해 산출물 전반의 표 서식이 통일된다
노하우 유출 방지
제공 가능한 부분만 선택해 담아 제출용 문서를 만들 수 있다
07유의할 점
  • 북마크는 표지 제목·목차·모범 표 서식 3개만 관리하면 되며, 시트별 삽입 위치는 북마크가 아니라 config의 챕터 경로로 결정된다
  • 표는 섹션 속성(w:sectPr) 바로 앞에 순서대로 삽입해야 챕터 제목보다 뒤섞이지 않는다 (검증 중 발견·조치된 이슈)
  • 모범 표를 찾지 못하거나 clone_header_row=False인 시트는 기본 표 스타일로 자동 대체된다
